# GENERIC-PROGRAMMING-Smart-Warehouse-Inventory-System-repo.
This project  designed to log and manage warehouse items using generic types. I built an Inventory class using Python's typing module, to allow the same inventory layout to handle completely different types of data cleanly without duplicating logic.

The code demonstrates how to set up separate inventory instances for product names as strings, stock counts as integers, and grouped serial numbers as lists. Each instance stores its specific data type and includes built-in methods to retrieve and print out the items alongside their underlying data types.
